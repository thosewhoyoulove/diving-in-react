# 学习路线与完整目录

这本书面向已经使用过 React、Vue、Redux 和 TypeScript，希望进一步理解 React 运行机制的前端开发者。

## 学习路线

```text
React 基础
  ↓
组件、Props 与 State
  ↓
Fiber、Diff、Lane 与调度
  ↓
Hooks、异步流和状态管理
  ↓
性能、工程化和复杂架构
  ↓
源码阅读、面试表达和综合项目
```

## 每章的固定结构

每章都会围绕以下顺序展开：

1. 本章学习目标
2. 生活化直觉
3. 最小可运行 TypeScript 示例
4. 代码逐行解释
5. React 内部运行机制
6. 常见错误和错误写法
7. 真实业务场景
8. 性能与架构考虑
9. 面试重点和标准回答
10. 面试官追问
11. 本章小结
12. 练习题与参考答案

## 版本说明

全书以 React 19 为当前项目主线，同时解释 React 18 中已经稳定的核心机制。涉及源码时，会明确区分：

- **官方行为**：公开 API 和文档明确保证的行为；
- **源码视角**：React 18/19 当前实现中的机制，可能随版本变化；
- **工程实践**：真实项目中的架构和性能经验。
